# DevSecOps Console v0.4.0

Dependabot Alert Noticeを拡張した、ローカル利用向けのDevSecOps Consoleの安定版配布です。実装済みの機能を配布するもので、DevSecOps全体ロードマップの完成版ではありません。

## 主な変更

- 共通のFindings一覧・詳細、資産との関連付け、同一CVEの関連表示を追加しました。
- Trivy JSON、GitHub Code Scanning、秘密値を含まないSecret Scanningメタデータ、EPSS/KEVのオフライン取り込みと証拠の保存に対応しました。
- 明示した時刻・入力・プロファイルに基づく優先度の参考試算と、再現用のCLI/APIを追加しました。参考試算は保存済みの判断や対応期限とは区別されます。
- GitHub接続の認証コンテキストと、記録済みの収集状態・失敗状態を確認できるようにしました。
- 更新処理の世代別受付・履歴検証と、同じ内部セッション内で保存結果を照合する復旧処理を追加しました。
- 既存のDependabot取得、AI評価、脆弱性RSS、通知、TUI、更新機能を引き継いでいます。

## 配布物

- Linux・Windows・macOS向けにamd64/arm64のバイナリとSHA-256チェックサムを配布します。
- macOSには起動・更新用スクリプトを同梱したZIPもあります。
- 配布用のMac設定はlocalhostのみで待ち受け、監視対象・通知先・自動AI評価は未設定です。認証情報は配布物に含みません。

## 利用前に確認すること

- データを持つ既存環境を更新する場合は、先に本体を停止して設定とDBをバックアップしてください。
- Web利用者の認証・権限管理、共通Findingのライブ継続収集、内部更新処理の実運用への接続、再起動をまたぐ所有権の復旧、Overview/Assetsの画面統合などは開発中です。Web UIを外部へ公開せず、ローカルで利用してください。
- 公開対象ソースのCheck/Trial CIでは、Linux amd64とmacOSの両アーキテクチャで全体のraceテストと試用バイナリの起動確認を行います。Windows amd64は静的検査・ビルド・更新機能テストと試用バイナリの起動確認、Linux/Windows arm64はクロスビルドです。
- 安定版Releaseの追加検証ではMac ZIPのチェックサム・起動スクリプト・実バイナリのバージョンと起動先URLを確認します。安定版のLinux/Windowsバイナリ自体の実行確認は含みません。
- 実データでの運用、利用者端末のGUI、署名・公証、運用DBのバックアップ復元はこの配布検証に含みません。macOSの配布物は署名・公証していません。

実装範囲と残作業は[全体ロードマップ](https://github.com/g-kari/devsecops-console/blob/main/docs/devsecops-roadmap.md)、導入方法は[README](https://github.com/g-kari/devsecops-console#readme)を参照してください。
