# DevSecOps Console v0.5.0

ローカル利用向けDevSecOps Consoleの安定版配布です。v0.4.0にOverview・Assets・記録済みIntegrationsの画面を加え、画面操作と依存関係を更新しました。DevSecOps全体ロードマップの完成版ではありません。

## 主な変更

- 保存済みデータを確認するOverview・Assets・Integrations画面を統合しました。記録済みの接続・収集状態の表示であり、すべての検出元をライブ収集する機能ではありません。
- 画面移動時のログ配信（SSE）の終了・復帰処理を修正し、古い接続からの通知や接続の増加を防ぎました。
- モバイル画面の操作ボタンの折り返し、ラベルの重なり、キーボードフォーカスの見やすさを改善しました。
- Goldmark v2、Bubble Tea v2、ANSI関連ライブラリへの移行と、GoReleaser関連の更新を行いました。
- lint・脆弱性検査・カバレッジ・ライセンス確認を含むCIを追加しました。

## 配布物

- Linux・Windows・macOS向けにamd64/arm64のバイナリとSHA-256チェックサムを配布します。
- macOSには起動・更新用スクリプトを同梱したZIPもあります。配布設定はlocalhost待受で、監視対象・通知先・自動AI評価は未設定です。認証情報は含みません。

## 更新元と互換性

- このReleaseの公開先は `g-kari/devsecops-console` です。既存端末の配信先や設定は変更していません。
- バイナリの更新元の既定値と、MacのSetup.command・Update.commandが参照する配信元は、引き続き `g-kari/dependabot-alert-notice` です。このReleaseの公開だけでは、それらの端末にConsoleの新版は自動配信されません。
- `--update-repo g-kari/devsecops-console` を明示したクライアント向けには、既存のバイナリ名・配布アーカイブ名・チェックサム形式を維持しています。これは配布形式の互換性であり、個々の端末での更新成功を保証するものではありません。
- 更新前に本体を停止し、設定とDBをバックアップしてください。バイナリ更新とMacパッケージ一式の更新は対象が異なります。

## 検証範囲と利用上の注意

- Check/Trial CIは、Linux amd64とmacOS両アーキテクチャのraceテスト、Windows amd64の静的検査・ビルド・更新機能テスト、および試用バイナリの起動確認を対象とします。Linux/Windows arm64はクロスビルドで、ネイティブ実行確認は含みません。
- Releaseの追加検証は、Mac ZIPのチェックサム、起動スクリプト、実バイナリのバージョンと起動先URLを対象とします。安定版のLinux/Windowsバイナリ自体の実行確認は含みません。
- ブラウザ検証は合成データと定めた経路・操作を対象とし、OS全体の通信を保証するものではありません。Windows利用者の実機、実データ運用、運用DBのバックアップ復元はこの配布検証に含みません。
- Web UIは外部へ公開せず、ローカルで利用してください。Web利用者の認証・権限管理などは開発中です。macOS配布物のDeveloper ID署名・公証は未設定です。

実装範囲と残作業は[全体ロードマップ](https://github.com/g-kari/devsecops-console/blob/main/docs/devsecops-roadmap.md)、導入方法は[README](https://github.com/g-kari/devsecops-console#readme)を参照してください。
